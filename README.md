# Student Portfolio and Academic Planner

A responsive, multi-page cybersecurity student portfolio and academic planner built with HTML, CSS, and JavaScript.

## Pages

- `index.html` — student homepage
- `about.html` — education, aspirations, skills, interests, and academic table
- `projects.html` — six cybersecurity project concepts and Gift's recorded audio introduction
- `password-checker.html` — browser-only educational password-strength demo
- `phishing-guide.html` — interactive guide to warning signs in a fictional phishing message
- `awareness-quiz.html` — five-question cybersecurity awareness quiz
- `privacy-checklist.html` — browser-only personal data privacy checklist
- `incident-guide.html` — browser-only account incident response checklist
- `safe-browsing.html` — interactive safe browsing guide and checklist
- `planner.html` — task manager with completion, deletion, and browser storage
- `contact.html` — validated contact form demonstration

## Before submission

The profile currently uses Gift Moses Ofem's chosen programme, school history, career interests, skills, hobbies, and portrait. The six cybersecurity demos are learning projects. Review their descriptions and add your own screenshots as you complete more work. The contact form validates locally and does not send messages to a server; add a real contact address only if you want it public.

Open `index.html` in a browser to view the site. It uses no build tools or dependencies.

## Hosting and repository

The site is static and can be hosted on a static web host such as GitHub Pages. To publish, create a GitHub repository, upload these website files and the `assets` folder, then enable GitHub Pages for the repository. Submit both the repository URL and published site URL.
